# Обновление каталога из Google Sheets

Каталог теперь загружается из локальных JSON файлов для максимальной производительности. Данные синхронизируются с Google Sheets по запросу.

## Как обновить каталог

После обновления данных в Google Sheets:

1. Откройте страницу **"Обновить каталог"** в верхнем меню сайта (или перейдите по адресу `/admin/update-catalog`)
2. Нажмите кнопку **"🔄 Обновить каталог"**
3. Дождитесь завершения обновления

Процесс обновления:
1. Подключение к Google Sheets
2. Загрузка всех категорий и товаров
3. Сохранение JSON файлов в `public/data/`:
   - `categories.json` - список всех категорий
   - `[category-id].json` - товары для каждой категории

## Преимущества

✅ **Мгновенная загрузка** - нет запросов к Google Sheets API при каждом открытии страницы
✅ **Быстрая работа** - все данные загружаются из локальных файлов
✅ **Простое обновление** - одна команда для синхронизации с Google Sheets

## Структура данных

### categories.json
```json
[
  {
    "id": "portable",
    "name": "Портативные газоанализаторы",
    "file": "portable.json"
  }
]
```

### [category-id].json
```json
[
  {
    "id": "fp23",
    "name": "Газоанализатор ФП23",
    "price": "850.00",
    "images": ["url1", "url2"],
    "generalInfo": ["info1", "info2"],
    "description": "Описание товара"
  }
]
```

## Требования

- Файл `google-sheets-credentials.json` должен быть настроен (см. `GOOGLE_SHEETS_SETUP.md`)
- Google Sheets API должен быть включен в проекте Google Cloud
