# Инструкция по созданию и настройке Google Forms опросника

## Шаг 1: Создание формы в Google Forms

1. **Откройте Google Forms**
   - Перейдите на https://forms.google.com
   - Войдите в свой Google аккаунт

2. **Создайте новую форму**
   - Нажмите на кнопку **"+ Пустая форма"** или выберите шаблон
   - Дайте форме название, например: "Анкета клиента ФАРМЭК"

3. **Добавьте вопросы в форму**
   - Нажмите на **"+ Добавить вопрос"**
   - Выберите тип вопроса:
     - **Краткий ответ** - для имени, email, телефона
     - **Абзац** - для комментариев и предложений
     - **Выбор из списка** - для выбора опыта, компании
     - **Шкала** - для оценки удовлетворенности (1-5)
     - **Множественный выбор** - для рекомендаций
     - **Флажки** - для множественного выбора
   - Добавьте все необходимые вопросы

4. **Настройте параметры формы**
   - Нажмите на **⚙️ Настройки** (вверху справа)
   - Настройте:
     - **Сбор адресов электронной почты** (если нужно)
     - **Ограничение на один ответ**
     - **Показывать строку прогресса**
     - **Перемешивать порядок вопросов** (если нужно)

## Шаг 2: Получение URL для встраивания

1. **Откройте форму для отправки**
   - Нажмите кнопку **"Отправить"** (вверху справа, зеленого цвета)

2. **Выберите способ встраивания**
   - В модальном окне нажмите на значок **"< >"** (HTML/iframe) - это третий значок
   - Вы увидите код iframe с URL формы

3. **Скопируйте URL из атрибута src**
   - URL будет выглядеть примерно так:
     ```
     https://docs.google.com/forms/d/e/1FAIpQLSdXXXXXXXXXXXXXXXXXXXXX/viewform?embedded=true
     ```
   - Скопируйте весь URL (важно: должен заканчиваться на `?embedded=true`)

## Шаг 3: Добавление URL в проект

У вас есть три способа добавить URL формы:

### Способ 1: Через переменную окружения (Рекомендуется)

1. **Создайте файл `.env`** в корне проекта (если его еще нет)
   ```
   GOOGLE_FORM_URL=https://docs.google.com/forms/d/e/YOUR_FORM_ID/viewform?embedded=true
   ```

2. **Или добавьте в существующий `.env`:**
   ```env
   GOOGLE_FORM_URL=https://docs.google.com/forms/d/e/YOUR_FORM_ID/viewform?embedded=true
   ```

3. **Замените `YOUR_FORM_ID`** на реальный ID вашей формы из URL

### Способ 2: Напрямую в nuxt.config.ts

1. Откройте файл `nuxt.config.ts`

2. Найдите секцию `runtimeConfig.public.googleFormUrl`

3. Замените пустую строку на URL вашей формы:
   ```typescript
   runtimeConfig: {
     public: {
       googleFormUrl: 'https://docs.google.com/forms/d/e/YOUR_FORM_ID/viewform?embedded=true'
     }
   }
   ```

### Способ 3: Временно в компоненте

1. Откройте файл `app/pages/about/questionnaire/index.vue`

2. В функции `onMounted()` раскомментируйте и укажите URL:
   ```javascript
   onMounted(() => {
     // Временно установить URL напрямую
     formUrl.value = 'https://docs.google.com/forms/d/e/YOUR_FORM_ID/viewform?embedded=true';
     
     // Или использовать из конфига
     // const config = useRuntimeConfig();
     // if (config.public?.googleFormUrl) {
     //   formUrl.value = config.public.googleFormUrl;
     // }
   });
   ```

## Шаг 4: Настройка прав доступа формы

1. **В Google Forms** нажмите на **⚙️ Настройки**

2. Перейдите на вкладку **"Представления"**

3. Убедитесь, что:
   - **"Любой пользователь с ссылкой может отвечать"** включено (если нужно)
   - Или установите нужные ограничения доступа

4. **Важно:** Форма должна быть доступна для просмотра тем, кто будет заполнять анкету

## Шаг 5: Проверка работы

1. **Запустите проект:**
   ```bash
   npm run dev
   ```

2. **Откройте страницу анкеты:**
   - Перейдите в меню **"О нас"** → **"Анкета"**
   - Или напрямую: `http://localhost:3000/about/questionnaire`

3. **Проверьте:**
   - Форма Google Forms отображается корректно
   - Можно заполнять и отправлять форму
   - Ответы сохраняются в Google Forms

## Дополнительные настройки

### Настройка внешнего вида формы

1. В Google Forms нажмите на **🎨 Палитра тем** (вверху справа)
2. Выберите цветовую схему или загрузите свой логотип
3. Выберите цвет заголовка и фона

### Получение ответов

Ответы сохраняются **прямо в Google Forms**. Вот как их найти:

#### Вариант 1: Просмотр ответов в Google Forms

1. **Откройте вашу форму в Google Forms:**
   - Перейдите на https://forms.google.com
   - Найдите вашу форму "123" (или другое название)
   - Откройте её

2. **Вкладка "Ответы":**
   - В верхней части формы нажмите на вкладку **"Ответы"**
   - Здесь вы увидите:
     - **"Сводка"** - статистика и графики по ответам
     - **"Вопрос"** - ответы по каждому вопросу отдельно
     - **"Индивидуальный"** - полные ответы каждого респондента
     - **Ссылку на Google Таблицы** - для экспорта всех ответов

3. **Просмотр в реальном времени:**
   - Все ответы появляются в реальном времени
   - Каждый новый ответ сразу виден в разделе "Ответы"

#### Вариант 2: Экспорт в Google Таблицы (Рекомендуется)

1. **Создайте связанную таблицу:**
   - В разделе "Ответы" нажмите на **значок таблицы** 📊 (создать таблицу)
   - Или нажмите на кнопку **"Создать таблицу"**

2. **Автоматическая синхронизация:**
   - Создастся новая Google Таблица
   - Все ответы будут автоматически экспортироваться туда
   - В таблице будет:
     - Столбец с временем отправки
     - Отдельные столбцы для каждого вопроса
     - Все ответы в структурированном виде

3. **Преимущества Google Таблицы:**
   - Удобная сортировка и фильтрация
   - Возможность анализа данных
   - Экспорт в Excel/CSV
   - Совместный доступ с коллегами
   - Возможность добавить формулы и графики

#### Вариант 3: Email уведомления

1. **Настройте уведомления:**
   - В Google Forms откройте **⚙️ Настройки**
   - Перейдите на вкладку **"Уведомления"**
   - Включите **"Уведомлять меня по электронной почте о новых ответах"**
   - Теперь вы будете получать email при каждом новом ответе

#### Вариант 4: Прямая ссылка на ответы

После создания таблицы с ответами, вы можете:
- Открыть таблицу и скопировать ссылку
- Поделиться ссылкой с командой
- Настроить права доступа (только просмотр или редактирование)

### Настройка уведомлений

1. В Google Forms нажмите на **⚙️ Настройки**
2. Перейдите на вкладку **"Уведомления"**
3. Включите уведомления на email при получении новых ответов

## Решение проблем

### Форма не отображается

- Проверьте, что URL содержит `?embedded=true`
- Убедитесь, что форма доступна для просмотра
- Проверьте консоль браузера на наличие ошибок

### Ошибка доступа

- Проверьте настройки доступа к форме в Google Forms
- Убедитесь, что включен доступ "Любой пользователь с ссылкой"

### Форма слишком маленькая или большая

- Отредактируйте `height` в атрибуте iframe (по умолчанию 800px)
- Или отредактируйте CSS в компоненте `.google-form-iframe`

## Примеры типов вопросов

### Обязательные поля (ФИО, Email, Телефон)
- **Тип:** Краткий ответ
- **Включить:** Обязательный вопрос

### Опыт работы
- **Тип:** Выбор из списка
- **Варианты:** Меньше 1 года, 1-3 года, 3-5 лет, Более 5 лет

### Удовлетворенность
- **Тип:** Шкала (1-5)
- **Минимум:** 1
- **Максимум:** 5

### Рекомендация
- **Тип:** Множественный выбор или Радиокнопки
- **Варианты:** Да, Нет

### Комментарии
- **Тип:** Абзац
- **Необязательный вопрос**
