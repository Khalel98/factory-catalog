# Локализация категорий

Категории теперь поддерживают локализацию через Google Sheets.

## Настройка Google Sheets

В листе **Categories** добавьте колонки для переводов:

| ID | Name (или NameRU) | NameKK |
|----|-------------------|--------|
| portable | Портативные газоанализаторы | Портативті газ анализаторлары |
| new | Новый тестовый | Жаңа тест |

### Формат колонок:

- **ID** (обязательно) - уникальный идентификатор категории. Имя файла генерируется автоматически как `{id}.json`
- **Name / NameRU** (обязательно) - русское название категории
- **NameKK** (опционально) - казахское название. Если не указано, используется русское

### Поддерживаемые форматы заголовков:

Система автоматически распознает следующие варианты названий колонок:
- `Name`, `NameRU`, `name_ru` - для русского названия
- `NameKK`, `name_kk` - для казахского названия

### Автоматическая генерация файлов:

Имя файла для товаров категории генерируется автоматически на основе ID: `{id}.json`
Например, для категории с ID `portable` будет создан файл `portable.json`

## Обновление каталога

После изменения категорий в Google Sheets:

1. Перейдите на страницу `/admin/update-catalog`
2. Нажмите кнопку "Обновить каталог"
3. Категории с переводами будут сохранены в `public/data/categories.json`

## Структура JSON файла

После обновления файл `categories.json` будет содержать:

```json
[
  {
    "id": "portable",
    "nameRU": "Портативные газоанализаторы",
    "nameKK": "Портативті газ анализаторлары"
  }
]
```

Имя файла для товаров генерируется автоматически: `portable.json` (на основе `id`)

## Использование в коде

Категории автоматически отображаются на выбранном языке пользователя. Компоненты `CatalogSidebar` и страницы каталога автоматически используют правильный перевод.
