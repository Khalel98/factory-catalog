# Руководство по использованию подкатегорий

## Что такое подкатегории?

Подкатегории позволяют создавать иерархическую структуру каталога. Например:
- **Портативные газоанализаторы** (основная категория)
  - **Базовые модели** (подкатегория)
  - **Профессиональные** (подкатегория)

## Настройка в Google Sheets

### 1. Обновите лист Categories

Добавьте колонку **ParentID** в лист Categories:

| ID | NameRU | NameKK | ParentID |
|----|--------|--------|----------|
| portable | Портативные газоанализаторы | Портативті газ анализаторлары | |
| portable-basic | Базовые модели | Негізгі модельдер | portable |
| portable-pro | Профессиональные | Кәсіби | portable |

**Правила:**
- Если **ParentID** пустой - это основная категория
- Если **ParentID** указан - это подкатегория
- **ParentID** должен совпадать с **ID** родительской категории

### 2. Создайте листы для подкатегорий

Для каждой подкатегории создайте отдельный лист в Google Sheets с именем, равным **ID** подкатегории.

Например:
- Лист `portable-basic` для подкатегории с ID `portable-basic`
- Лист `portable-pro` для подкатегории с ID `portable-pro`

Структура листа подкатегории такая же, как и для основной категории (см. документацию по товарам).

## Как это работает

### Отображение в каталоге

- **Основные категории** отображаются в боковом меню
- **Подкатегории** отображаются вложенными под родительской категорией
- При клике на основную категорию показываются товары из неё и из всех её подкатегорий
- При клике на подкатегорию показываются только товары из этой подкатегории

### Хранение данных

- Каждая категория (включая подкатегории) имеет свой файл: `{id}.json`
- Товары из подкатегории сохраняются в файл подкатегории
- Товары из основной категории сохраняются в файл основной категории

### Breadcrumbs (хлебные крошки)

При просмотре товара из подкатегории в breadcrumbs отображается:
```
Главная > Каталог > Основная категория > Подкатегория > Товар
```

## Пример использования

1. **Создайте основную категорию:**
   - В листе Categories: `ID = "portable"`, `ParentID = ""`
   - Создайте лист `portable` для товаров

2. **Создайте подкатегорию:**
   - В листе Categories: `ID = "portable-basic"`, `ParentID = "portable"`
   - Создайте лист `portable-basic` для товаров подкатегории

3. **Обновите каталог:**
   - Перейдите на `/admin/update-catalog`
   - Нажмите "Обновить каталог"

4. **Результат:**
   - В боковом меню появится "Портативные газоанализаторы"
   - При раскрытии покажется "Базовые модели"
   - При выборе основной категории покажутся товары из обеих категорий
   - При выборе подкатегории покажутся только товары из подкатегории

## Важные замечания

⚠️ **ID категорий должны быть уникальными** - не используйте одинаковые ID для разных категорий

⚠️ **ParentID должен существовать** - убедитесь, что родительская категория создана до создания подкатегории

⚠️ **Имя листа = ID категории** - лист в Google Sheets должен иметь имя, равное ID категории

✅ **Многоуровневая вложенность** - в будущем можно добавить поддержку нескольких уровней вложенности
