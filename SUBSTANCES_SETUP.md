# Подбор газоанализаторов

## Подбор веществ (Substances)

Раздел «Подбор веществ» в каталоге позволяет показывать товары, сгруппированные по измеряемому веществу.

## 10 веществ по умолчанию

1. Пропан (C3H8), % об. доли — `propan`
2. Метан (CH4), % об. доли — `metan`
3. Водород (H2), % об. доли — `vodorod`
4. Монооксид углерода (CO), масс. конц. мг/м³ — `monooksid-ugleroda`
5. Кислород (O2), % об. доли — `kislorod`
6. Давление, кПа — `davlenie`
7. Сероводород (H2S), масс. конц. мг/м³ — `serovodorod`
8. Аммиак (NH3), масс. конц. мг/м³ — `ammoniak`
9. Пары бензина и нефтепродуктов (Ex), % НКПР — `pary-benzina`
10. Углекислый газ (CO2), % об. доли — `uglekislyj-gaz`

## Структура данных

### Лист «Substances» в Google Sheets

| id     | name                        | nameKz (каз.)   | description | descriptionKz (каз.) | productIds    |
|--------|-----------------------------|-----------------|-------------|----------------------|---------------|
| propan | Пропан (C3H8), % об. доли   | Пропан (C3H8)... |             |                      | fp34, fp23    |
| metan  | Метан (CH4), % об. доли     | Метан (CH4)...   |             |                      | fp34, fst-03v1|
| ...    | ...                         | ...              | ...         | ...                  | ...           |

- **id** — уникальный идентификатор (slug для URL)
- **name** — отображаемое название (рус.)
- **nameKz** — название на казахском (при выборе языка КЗ показывается вместо name)
- **description** — необязательное описание (рус.)
- **descriptionKz** — описание на казахском (при выборе языка КЗ показывается вместо description)
- **productIds** — ID товаров через запятую (без пробелов или с пробелами — оба варианта допустимы)

### Файл `public/data/substances.json`

```json
[
  {
    "id": "propan",
    "name": "Пропан (C3H8), % об. доли",
    "nameKz": "Пропан (C3H8), % көлемдік үлес",
    "description": "",
    "descriptionKz": "",
    "productIds": ["fp34", "fp23"]
  }
]
```

## Редактирование

### Через Google Sheets

1. Создайте лист «Substances» в таблице (если его нет)
2. Добавьте строку заголовков: `id`, `name`, `nameKz`, `description`, `descriptionKz`, `productIds`
3. Заполните строки веществ
4. **Синхронизация:** перейдите в админку на страницу **«Обновить каталог»** (`/admin/update-catalog`) и нажмите кнопку **«Обновить каталог»**. Данные будут прочитаны из Google Sheets и записаны в `public/data/substances.json` и `public/data/applications.json`. После этого изменения из таблицы появятся на сайте.

### Через админ-панель (isAdmin)

1. Включите режим администратора: `localStorage.setItem('isAdmin', 'true')`
2. Перейдите на `/admin/substances`
3. Редактируйте вещества и ID товаров
4. Нажмите «Сохранить вещества»

## Маршруты веществ

- `/catalog/substances` — список всех веществ
- `/catalog/substances/{id}` — товары для конкретного вещества (например `/catalog/substances/propan`)

## Подбор по сфере применения (Applications)

14 сфер по умолчанию: Котельные и топочные, Парковки гаражи автостоянки, Коммунально-бытовое хозяйство, Объекты водоснабжения, Тепличные комплексы, Строительный комплекс, Теплоэнергетический комплекс, Газовые хозяйства, Станции техобслуживания, Автозаправки, Сельскохозяйственные объекты, Предприятия нефтегазового комплекса, Аккумуляторные помещения, Холодильные камеры.

### Лист «Applications» в Google Sheets

Структура идентична Substances: id, name, nameKz, description, descriptionKz, productIds. Столбцы **nameKz** и **descriptionKz** — название и описание на казахском для отображения при выборе языка КЗ.

### Маршруты сфер

- `/catalog/applications` — список всех сфер
- `/catalog/applications/{id}` — товары для сферы (например `/catalog/applications/kotelnye-i-topochnye`)

### Админка

`/admin/applications` — управление сферами (при isAdmin)

## Синхронизация после правок в Google Sheets

Если вы изменили данные **напрямую в Google Sheets** (листы Substances, Applications, Categories или листы категорий товаров):

1. Откройте в браузере страницу **Обновить каталог**: `/admin/update-catalog`
2. Нажмите кнопку **«Обновить каталог»** (или «🔄 …» из перевода)
3. Сервер прочитает все данные из таблицы и перезапишет файлы в `public/data/` (categories.json, substances.json, applications.json и файлы категорий товаров)
4. Обновите страницу сайта — изменения из таблицы будут отображаться

Синхронизация идёт **из Google Sheets в приложение** (таблица — источник истины при нажатии «Обновить каталог»).
