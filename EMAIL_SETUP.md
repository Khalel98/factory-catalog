# 📧 Обратная связь через StaticForms (для SSG / Nuxt generate)

Формы обратной связи и заявок работают **без сервера**: отправка идёт напрямую в [StaticForms](https://www.staticforms.xyz/). Это подходит для статического деплоя (`nuxt generate`), где нет API `/api/send-email`.

## Шаг 1: Регистрация и API ключ

1. Перейдите на [StaticForms — регистрация](https://www.staticforms.xyz/register).
2. Зарегистрируйтесь (достаточно email, без карты).
3. Подтвердите email по ссылке из письма.
4. В личном кабинете скопируйте **API key** (формат вида `sf_abc123...`).

**Важно:** этот ключ будет использоваться в браузере (публичный), так и задумано в StaticForms.

---

## Шаг 2: Ключ в google-sheets-credentials.json

Ключ StaticForms хранится в том же файле, что и остальные учётные данные проекта.

1. Откройте файл **`google-sheets-credentials.json`** в корне проекта.
2. Добавьте поле **`static_forms_api_key`** (или вставьте ключ в уже добавленное поле):

```json
"static_forms_api_key": "sf_ваш_ключ_из_кабинета_staticforms"
```

**Пример фрагмента файла:**
```json
  "google_form_url": "https://docs.google.com/forms/d/e/...",
  "recipient_email": "khalel.demeuov@gmail.com",
  "static_forms_api_key": "sf_abc123def456ghi789jkl012mno345"
```

3. Сохраните файл и перезапустите dev-сервер или пересоберите проект (`npm run generate`).

**Деплой:** при сборке на CI (Vercel, Netlify и т.д.) файл `google-sheets-credentials.json` должен быть доступен в корне проекта в момент запуска `nuxt generate`, и в нём должен быть заполнен `static_forms_api_key`. Обычно это делают через секреты: подставляют весь JSON или только ключ в файл перед билдом.

---

## Шаг 3: Проверка работы

1. Запустите сайт (например, `npm run dev` или откройте сгенерированный статический сайт).
2. Откройте страницу **Контакты** и отправьте форму обратной связи.
3. Откройте форму заявки на товар (если есть) и отправьте заявку.
4. Проверьте:
   - почту, привязанную к аккаунту StaticForms;
   - раздел «Submissions» в [кабинете StaticForms](https://www.staticforms.xyz/).

Если ключ не задан, формы покажут сообщение: «Форма не настроена (отсутствует API ключ StaticForms)».

## Внешний вид писем (шапка и язык)

**Что можно изменить у нас:**  
Тема письма задаётся с нашего сайта по-русски:
- обратная связь: **«Обратная связь с сайта»**;
- заявка на товар: **«Новая заявка: [название товара]»** или **«Новая заявка с сайта»**.

**Локализация подписей полей:**  
В письме мы отправляем поля с **русскими именами** (ФИО, Телефон, Email, Товар, Тип заявителя, Компания, Сообщение и т.д.), поэтому в теле письма подписи к значениям отображаются по-русски.

**Что нельзя изменить:**  
Верхняя шапка письма (логотип/заголовок от StaticForms) и служебный текст — это шаблон сервиса, он на английском и через API не меняется.

Если нужны полностью свои письма на русском (своя шапка и текст), варианты:
- написать в [поддержку StaticForms](https://www.staticforms.xyz/contact) с запросом кастомизации;
- на плане Pro: настроить **webhook** и принимать заявки на своём сервере/сервисе, а письма отправлять самим (например через Resend, SendGrid или свой SMTP) с любым шаблоном.

## Особенности и лимиты

- **Без сервера:** запросы идут с браузера на `https://api.staticforms.dev/submit`, сервер Nuxt для форм не нужен.
- **SSG:** подходит для `nuxt generate` и любого статического хостинга.
- **Бесплатный план:** например, 500 писем в месяц; лимиты уточняйте на [StaticForms Pricing](https://www.staticforms.xyz/pricing).
- **Реквизиты:** в форме заявки для юр. лиц — текстовое поле (textarea), без загрузки файлов.
- **Спам-защита:** в кабинете StaticForms можно включить reCAPTCHA или honeypot.

Старая настройка через Gmail SMTP и `server/api/send-email` больше не используется; при статическом деплое тот API всё равно недоступен.
