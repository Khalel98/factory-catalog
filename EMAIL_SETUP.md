## Шаг 1: Создание App Password в Google

### 1.1. Включение двухфакторной аутентификации

**Важно:** Для использования App Password необходимо включить двухфакторную аутентификацию.

1. Откройте [Настройки аккаунта Google](https://myaccount.google.com/)
2. Перейдите в раздел **"Безопасность"** (левое меню)
3. Найдите раздел **"Вход в аккаунт Google"**
4. Найдите пункт **"Двухэтапная аутентификация"**
5. Если она **выключена**:
   - Нажмите **"Начать"**
   - Следуйте инструкциям для настройки (обычно через телефон)
   - Подтвердите настройку

### 1.2. Создание пароля приложения

1. В том же разделе **"Безопасность"** найдите **"Пароли приложений"**
   - Или перейдите по прямой ссылке: [Пароли приложений](https://myaccount.google.com/apppasswords)
   
2. Если вы не видите этот пункт:
   - Убедитесь, что двухфакторная аутентификация включена
   - Возможно, потребуется войти в аккаунт Google еще раз

3. На странице "Пароли приложений":
   - В поле **"Приложение"** выберите **"Почта"**
   - В поле **"Устройство"** выберите **"Другое устройство"**
   - Введите название: **"Газсервис-7 сайт"**
   - Нажмите **"Создать"**

4. **ВАЖНО:** Google покажет вам **16-значный пароль** (например: `abcd efgh ijkl mnop`)
   - Этот пароль показывается **только один раз**!
   - **Скопируйте его сразу** (можно убрать пробелы: `abcdefghijklmnop`)
   - Сохраните в безопасном месте

## Шаг 2: Настройка переменных окружения

### 2.1. Создание файла .env

1. Откройте корневую папку проекта: `factory-catalog`
2. Создайте новый файл с именем `.env` (с точкой в начале!)
   - Если файл уже существует, откройте его для редактирования

### 2.2. Добавление настроек

Откройте файл `.env` и добавьте следующие строки:

```env
# Gmail SMTP настройки
GMAIL_USER=khalel.demeuov@gmail.com
GMAIL_APP_PASSWORD=ваш_16_значный_пароль_приложения
```

**Пример:**
```env
GMAIL_USER=khalel.demeuov@gmail.com
GMAIL_APP_PASSWORD=abcdefghijklmnop
```

**Важно:**
- `GMAIL_USER` - это ваш полный email адрес Gmail
- `GMAIL_APP_PASSWORD` - это 16-значный пароль приложения (без пробелов)
- Не ставьте кавычки вокруг значений
- Не добавляйте лишние пробелы

### 2.3. Сохранение файла

Сохраните файл `.env` в корне проекта.

## Шаг 3: Проверка работы

### 3.1. Перезапуск сервера

1. Остановите текущий dev сервер (если запущен):
   - Нажмите `Ctrl + C` в терминале

2. Запустите сервер заново:
   ```bash
   npm run dev
   ```

### 3.2. Тестовая отправка

1. Откройте сайт в браузере
2. Перейдите на страницу контактов или откройте форму заявки
3. Заполните форму тестовыми данными
4. Отправьте форму
5. Проверьте почту `khalel.demeuov@gmail.com`
   - Письмо должно прийти в течение нескольких секунд
   - Проверьте папку "Входящие" и "Спам"

### 3.3. Что должно прийти

В письме будет:
- Тип заявителя (физическое/юридическое лицо)
- Контактные данные (ФИО, телефон, email)
- Название товара (если указано)
- Сообщение (если указано)
- Красивое HTML-оформление

## Устранение проблем

### ❌ Ошибка: "Gmail credentials not configured"

**Причина:** Не найдены переменные окружения

**Решение:**
1. Убедитесь, что файл `.env` создан в корне проекта
2. Проверьте, что переменные названы правильно: `GMAIL_USER` и `GMAIL_APP_PASSWORD`
3. Перезапустите сервер после изменения `.env`

---

### ❌ Ошибка: "Invalid login" или "Authentication failed"

**Причина:** Неправильный email или пароль приложения

**Решение:**
1. Проверьте, что `GMAIL_USER` содержит полный email (например: `khalel.demeuov@gmail.com`)
2. Убедитесь, что используете **App Password**, а не обычный пароль Gmail
3. Проверьте, что пароль скопирован правильно (16 символов, без пробелов)
4. Создайте новый App Password, если старый не работает

---

### ❌ Ошибка: "Less secure app access"

**Причина:** Старая настройка безопасности

**Решение:**
- Это нормально! App Password работает без "менее безопасных приложений"
- Убедитесь, что используете именно **App Password**, а не обычный пароль
- Двухфакторная аутентификация должна быть включена

---

### ❌ Письма не приходят

**Проверьте:**

1. **Папка "Спам"**
   - Письма могут попадать в спам при первой отправке
   - Отметьте письмо как "Не спам"

2. **Консоль сервера**
   - Откройте терминал, где запущен `npm run dev`
   - Проверьте, есть ли ошибки (красный текст)
   - Скопируйте ошибку для диагностики

3. **Переменные окружения**
   - Убедитесь, что файл `.env` сохранен
   - Проверьте синтаксис (нет лишних пробелов, кавычек)
   - Перезапустите сервер

4. **Лимит Gmail**
   - Gmail позволяет отправлять до 500 писем в день
   - Если превышен лимит, подождите до следующего дня

---

### ❌ "Пароли приложений" не отображается

**Причина:** Двухфакторная аутентификация не включена или аккаунт корпоративный

**Решение:**
1. Убедитесь, что двухфакторная аутентификация **включена**
2. Если используете корпоративный Google Workspace:
   - Обратитесь к администратору для разрешения App Passwords
   - Или используйте личный Gmail аккаунт

## 🔒 Безопасность

⚠️ **Важно:**

1. **Никогда не коммитьте файл `.env` в Git!**
   - Файл уже добавлен в `.gitignore`
   - Не публикуйте пароли в открытом доступе

2. **Храните App Password в безопасности**
   - Не передавайте его третьим лицам
   - Если пароль скомпрометирован, удалите его и создайте новый

3. **Регулярно проверяйте активность**
   - Периодически проверяйте список App Passwords в настройках Google
   - Удаляйте неиспользуемые пароли
